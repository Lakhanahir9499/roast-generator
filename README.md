# Desi Roast Generator

A fun, AI-powered desi-style roast generator that creates Hindi roasts, meme-style images, and voice-based roast audio.

## Features
- Hindi/Desi Roast Lines using OpenAI GPT
- Voice Roast using Google TTS (gTTS)
- Meme Image Generator (html2canvas)
